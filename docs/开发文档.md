# Gungun 开发文档

## 1. 产品约束

记录时间：2026-11-27（Asia/Shanghai）。本仓库从空 main 建立，内部开发分支为 development。核心功能全部集成后才创建正式版本；不发布阶段性正式版本。首个统一交付版本为 1.0.0。按用户最终选择，macOS 仅构建 arm64，适用于 M1 Pro；fq 保留 Linux amd64 / arm64。

管理端固定 Electron + electron-vite、React、TypeScript、Tailwind CSS、shadcn/ui（Base UI）、lucide-react、Node.js、node:sqlite、pnpm。fq 为 Go 标准库实现，CGO_ENABLED=0，输出 Linux amd64 / arm64 单文件程序。服务部署、客户端测速与链路统一使用 sing-box；Mihomo 仅为 YAML 订阅导出格式，不下载或运行 Mihomo。节点导入同样限定这六类协议，其他协议明确拒绝，后续可扩展。暂不实现 Xray、VLESS ENC、sing-box JSON 订阅导出、在线订阅服务器、NAT 自动识别 / 端口跳跃、复杂分流和 MRS。

## 3. 数据来源与模型

远程 `/etc/gungun/state.json` 是服务真实来源；禁止本机节点编辑隐式修改远程。Gungun SQLite 是节点、Tag、链路、测速和任务来源。VPS 节点通过 SSH 执行 `fq export --json` 手动同步；不通过 Tunnel 提供订阅。

SQLite 开启 WAL、busy_timeout、foreign_keys，版本表记录迁移。对象按 kind + ID 保存结构化 JSON。所有入口在写入前通过 Zod。节点 ID 在 VPS 导出中为 hostId:serviceId:access，Argo 额外包含客户端端口，因此同步可保留链路引用。外部订阅按协议、端点与认证匹配原 ID。更新在 SQLite 事务内执行；原节点消失时清理受影响链路，手动删除前必须确认影响。测试结果按主体类型 + 主体 ID + 测试源唯一覆盖。

VPS 每台一个 Tag。所有节点是虚拟分组；链式代理是独立虚拟 Tag。聚合 Tag 仅存 tagIds，读取时递归解析并去重；校验循环引用，不复制节点。已有原始节点的分组不能直接改为聚合，须先移动节点，避免不可见的遗留数据。一个 Tag 可以加入多个聚合。

## 4. SSH 与权限

ssh2 执行实际握手和 direct-tcpip 跳板通道，SSH 连接失败不阻止保存。首次连接或指纹变更明确拒绝，用户独立核验 SHA256 后保存信任。配置导出到 `~/.ssh/gungun/config`，不编辑用户主配置。密钥生成到 `~/.ssh/gungun/`，轮换使用新路径，旧密钥保留。

SSH 主机可以是公网或 Tailscale 地址；可查询本机和远程 Tailscale 状态。Tailscale 网络加入仍由用户在 Tailscale 中完成。fq 服务安装要求 Linux systemd；非 root 用户需要预先配置 `sudo -n`，不会绕过交互 sudo。

本地数据目录 0700、数据库及完整备份 0600。按要求不用 Keychain，Cloudflare Global API Key 保存在本地数据库；本地备份包含凭据。渲染进程读取的设置 Key 使用掩码，Mac 主进程通过 X-Auth-Email / X-Auth-Key 直接访问 Cloudflare，不把 Global Key 发给 fq。Tunnel scoped token 是 cloudflared 运行必需凭据，可传到对应 VPS 并以 0600 保存。

## 5. 远程事务

fq 使用 flock 拒绝同一主机并发写入。Gungun 任务中心同时处理不同 VPS，单 VPS 任务串行。

变更顺序：读取真实配置、完整备份、生成 stage 配置、运行 sing-box check / caddy validate、原子替换文件、重启目标服务、检查 systemd 与监听、成功；任一步失败恢复备份并验证原配置。回滚失败独立报告，保留备份 ID。备份包含 state、sing-box、Caddy、Tunnel 环境、证书与私钥；最后原子写入 manifest.json，记录每个文件是否存在及 SHA256。恢复在任何修改前完整验证清单与全部校验和，损坏或未完成的备份被拒绝。restore 在恢复前也创建当前备份，避免不可逆恢复。

Cloudflare 变更维护撤销列表，按逆序补偿 DNS、Tunnel 路由、回源规则和远程配置。编排串行化 Cloudflare 更新，避免同账号回源规则修改竞争。不静默覆盖不同类型的同名 DNS。删除远程网站时 DNS 保留，避免删除外部可能正在使用的解析记录。

任务持久化类型、VPS、进度、步骤、错误、结果与时间。进程重启把 running / queued 标为 interrupted，避免假装任务已完成。任务日志隐藏常见密码 / token 字段。批量测试和优选按实际完成项更新进度，结果显示通过及失败数量；并发任务共享全局测试配额。日志和状态读取不获取写锁，可在远程变更期间查看诊断。

## 6. 协议与接入能力

| 协议            | 直连    | CDN | Argo | 证书                                |
| --------------- | ------- | --- | ---- | ----------------------------------- |
| Hysteria2       | 是，UDP | 否  | 否   | DNS-01 TLS                          |
| TUIC            | 是，UDP | 否  | 否   | DNS-01 TLS                          |
| AnyTLS          | 是，TCP | 否  | 否   | DNS-01 TLS                          |
| Snell v6        | 是，TCP | 否  | 否   | PSK，无普通 TLS 证书                |
| VLESS + WS      | 是      | 是  | 是   | 直连 / CDN 用 TLS；Tunnel 内部 HTTP |
| VLESS + Reality | 是      | 否  | 否   | X25519 + Short ID，不作普通证书处理 |

每协议默认一个实例，添加其他协议会合并远程状态。普通 VPS 端口自动选择可用端口；NAT 必填内部和公网映射端口。Edge、公网回源与内部监听独立建模。CDN HTTPS Edge 支持 443、2053、2083、2087、2096、8443。CDN 回源默认 TLS，Cloudflare 的区域 SSL 模式需支持 HTTPS 回源；不会擅自修改整个 Zone 的 SSL 策略。

每台 VPS 独立随机 namespace；直连默认 node.namespace.zone，CDN / Argo 优先 cdn / argo.namespace.zone。先查询 Cloudflare 实际生效的 Edge 证书；建议结构未被覆盖而一级名称被覆盖时，自动域名改用 cdn-namespace.zone / argo-namespace.zone；自定义域名不做静默替换。服务端证书保留独立泛域名并增加所需 SAN，续期保留当前服务域名。不会自动订购付费 Edge 证书。Tunnel 每台一个，API 下发多个 ingress hostname → 内部端口，固定 404 尾路由。Argo WS 内部只监听 127.0.0.1，客户端导出 443 TLS 与 80 HTTP 两条记录。

## 7. 证书、网站与 WARP

fq 生成并保留 ECDSA 私钥，向 Mac 只返回 CSR。Mac 用 Let's Encrypt DNS-01 在 Cloudflare 建立 TXT、等待传播、完成 ACME、清理 TXT、回传证书。默认包含独立 namespace 泛域名，网站自定义域名作为 SAN；Reality 不参与普通 TLS。证书安装验证私钥匹配及到期时间，再事务应用。

Gungun 启动后和每日检查临近 30 天到期证书。Global Key 不能发 VPS，因此自动续期依赖 Mac 在线且能通过 SSH 访问 VPS；长期无人值守必须保持 Mac 运行或手动提前续期。

网站使用 Caddy JSON，不依赖 1Panel。域名、目标地址 / 端口、HTTP / HTTPS 回源独立配置；上游 HTTPS 验证证书。相同内部端口仅允许兼容的传输方式：多个 HTTPS 网站可共用，Argo 内部 HTTP 不能与 HTTPS 网站混用同端口。公网直连优先，NAT 使用用户提供映射，无入站时选择 Argo。Caddy 管理证书由 Gungun DNS-01 流程提供，禁止 Caddy 意外另行触发 HTTP-01。

WARP 由 fq 使用 Cloudflare 官方 apt 源安装，warp-cli 注册、proxy mode、40000 SOCKS、connect。暂支持列出的 Debian / Ubuntu 发行版本。sing-box 按 inbound tag 选择 DIRECT / WARP，不改变 SSH 系统路由。断开 WARP 时选用它的协议会连接失败，用户可将这些协议改回 DIRECT。

## 8. 链式代理与测试

Chain 保存 nodeIds 的有序列表，首版界面默认两跳，可增加到八跳。导出时为每条链生成独立的各跳实例：第 n 跳 `dialer-proxy` 指向 n-1 跳，MATCH 选择最后一跳。原始节点更新后无需复制或重建链路。禁止将链路伪装成普通 V2Ray 分享链接，必须用 Mihomo YAML 导出。

当前拒绝第二跳及后续跳的 Hysteria2 / TUIC UDP 拨号，保留第一跳 UDP 协议承载 TCP 的能力。其他组合仍可能受核心实现 / TLS / MTU / 线路影响，保存前校验、保存后实际测试。逐跳测试第一个节点和各前缀链路，报告每跳错误；前一跳失败时后续跳明确标记未测试，避免误报后续节点自身故障；最终执行完整链路下载。结果与普通节点分开保存。

测速启动独立 sing-box 进程，真连接请求经过真实代理后访问目标 URL，排除核心启动耗时；速度按实际字节和耗时计算 MB/s。Mac 用 curl，VPS 用 fq bench 与 Go HTTP client。全局 ConcurrencyGate 限制所有测试与优选任务的总并发，默认 10。测试范围为当前 Tag，测试源可多选；排除源 VPS 自身节点和包含自身节点的链路。

优选 IP 从 Cloudflare 官方 IP 段取样，也可手填候选；只临时替换 Address，SNI / Host / 认证保持不变。全部执行真实延迟与下载测试，用户选择才更新本地节点，不改远程服务。

## 9. UI 风格

参考 Codex Desktop，左侧可折叠导航，右侧独立工作区。背景 #17191c，侧栏 #111315，表面 #1e2125，正文 #eceef1，辅助 #989fa9，主要操作 #a7c6ee。系统字体使用 macOS SF / 苹方，地址和日志使用 Menlo。24–26 px 页面标题，13 px 正文，11–12 px 辅助信息。层级靠间距、细边框和工作区结构表达，不填充虚构示例数据。

## 10. 构建与发布

CI 在 main / development、PR 和手动触发，执行冻结安装、lint、TypeScript、前端 / SQLite / SSH 测试、Go race、真实六协议和链路测试、构建。macOS arm64 使用 macos-15，实际启动 Electron 并运行桌面工作流测试。开发阶段暂时关闭 DMG 生成和安装包挂载验证；最终交付阶段再由正式发布工作流执行 DMG 打包、安装和启动验收。

正式发布工作流仅通过 workflow_call 调用，不响应 tag push 或手动触发。main 的 CI 成功且 docs/release.json ready=true 时，Final release gate 才会启动完整发布流程：Linux 与 macOS arm64 验证成功后，将最终资产暂存于草稿 Release，统一生成 SHA256SUMS、附加报告与文档并公开发布。普通 CI 和手动测试不上传临时 Artifact。

签名可配置 CSC_LINK / CSC_KEY_PASSWORD；公证另需 APPLE_ID / APPLE_APP_SPECIFIC_PASSWORD / APPLE_TEAM_ID。未配置时不会声称签名公证成功。核心版本固定 sing-box 1.14.4、cloudflared 2026.11.2、Caddy 2.10.2，下载按官方 Release asset digest 验证。

### 打包环境问题记录

- pnpm 将可选 cpu-features / ssh2 原生构建设为 false；ssh2 的纯 JavaScript 实现已通过真实 SSH 与跳板测试。electron-builder 的默认重建仍会尝试编译可选 cpu-features，因缺少其安装脚本生成文件失败。当前使用内置 node:sqlite 且没有必需原生 Node 依赖，显式 npmRebuild=false；今后引入必需原生模块时须重新设计 ABI 重建配置。
- 当前执行容器禁止 Unix / netlink socket，无法在此处运行完整 Electron / sing-box 服务；真实运行验证在 GitHub Linux / macOS runner 完成，不把该容器限制隐藏成通过结果。

- 连续受控重启可能触发 systemd 默认启动限流，连带阻止回滚后的正常配置启动。每次明确的配置应用 / 回滚重启前 reset-failed，后台 on-failure 重启仍受服务限流约束；失败时附加 journal 以保留真实错误原因。


## 外观与基础组件

默认跟随系统，另提供浅色和深色。主题保存在 SQLite 设置中，启动时先恢复 Electron nativeTheme，所有窗口通过统一通知同步；终端只更新配色，不重建 SSH 会话。系统主题变化实时生效。使用 shadcn/ui Base UI 官方组件源码与 Tailwind CSS 4：按钮、输入、选择、复选、对话框、表格、标签页及进度等实际用于业务页面。组件位于 renderer/src/components/ui；布局与语义颜色统一支持浅色和深色。

链路执行使用 sing-box outbound detour：后续跳引用前一跳，route.final 指向最终出口。Mihomo 导出继续用 dialer-proxy 以保持客户端兼容。测速使用独立直连健康入口等待核心就绪，不将启动时间计入延迟，也不重试失败的代理请求。整张证书 SHA256 pin 与 sing-box SPKI pin 不等价，导入可保留但执行明确报错，不能静默降级证书验证。

当前执行核心兼容性：Hysteria2 / TUIC 直接接 VLESS WS / Reality 的四种组合在真实下载回归中不稳定，暂时明确拒绝创建和执行。可使用 AnyTLS / Snell 作为中间跳，或选择 TCP 第一跳。已支持的组合需通过实际连接和下载；能力拒绝测试与真实连通测试分别计数，不把拒绝当成连通成功。


## 本地开发工具链（2026-11-27）

本地开发不要求用户全局安装 Go。`pnpm prepare:dev` 在 macOS Apple Silicon 上调用 `scripts/ensure-go.mjs`，优先复用项目 `.tools/go` 或系统中精确匹配 Go 1.25.4 的工具链；若不存在，则读取 go.dev 官方版本元数据，下载 macOS arm64 官方归档并校验 SHA256，再解压到 `.tools/go`。随后构建 Linux amd64 / arm64 fq，并通过官方 Release digest 下载 sing-box。`pnpm fq:build` 与 `pnpm test:go` 自动复用同一工具链。`.tools/` 被 gitignore 排除，不提交本地工具二进制。
