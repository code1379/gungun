# Gungun 使用说明

## 当前版本：从源码运行

当前按要求暂停 DMG 生成和临时 Actions Artifact 上传。Apple Silicon Mac（含 M1 Pro）安装 Node.js 24 和 pnpm 12.23.0 后，在项目根目录运行：

```sh
pnpm setup:install
pnpm prepare:dev
pnpm dev
```

`pnpm setup:install` 自动适配 HTTP_PROXY / HTTPS_PROXY；不需要预装 Go。首次准备会下载并校验项目私有 Go 1.25.4、构建两种 Linux 架构的 fq，以及准备 macOS arm64 sing-box。修改 fq 后运行 `pnpm fq:build`。需要访问 Go 官方下载站和 GitHub 官方 Release。

### 后续安装包

恢复正式发布后，仅提供 Apple Silicon arm64 DMG，不构建 Intel 版本。正式 Release 必须重新通过 DMG 构建、挂载、安装、启动与包内资源验证，并附带 SHA256SUMS。未配置 Apple 凭据时会标明未签名、未公证；源码版测试通过不代表安装包已完成验收。

### 单独安装 fq

Linux 的 x86_64 对应 fq-linux-amd64，aarch64 对应 fq-linux-arm64。当前可使用 `pnpm prepare:dev` 在 `resources/bin/` 生成的对应二进制；后续正式下载应先按 SHA256SUMS 校验，再运行（下例为 amd64）：

```sh
chmod +x fq-linux-amd64
sudo install -m 0755 fq-linux-amd64 /usr/local/bin/fq
sudo fq install
sudo fq core update sing-box
fq version --json
```

这些命令安装程序、服务单元和核心；协议、网站、域名等配置通过 Gungun 部署中心创建。也可使用 fq apply 从 stdin 提交 schemaVersion=1 的配置。Gungun 的“安装 / 更新 fq”会自动识别架构并完成上传和安装，通常更方便。

## 首次设置

1. 在设置填写 Cloudflare 账号邮箱和 Global API Key，点击“保存并读取 Zone”。Key 保留在 Mac，不发送到 VPS。
2. 填写 Let's Encrypt 邮箱。证书申请会接受该服务条款。
3. 生成 Ed25519 主密钥，或选择已有私钥。将公钥加入远程 authorized_keys；已有密码连接也可先登录后添加。
4. 测速默认最大并发 10、Mac 本机、真连接 URL 和下载 URL 可按线路调整。速度单位 MB/s。

本地数据库和导出备份包含敏感凭据，不使用 Keychain。请保护 macOS 用户账号及备份。

## VPS 与 SSH

添加主机时手动选择公网 / NAT，填写 SSH 地址、端口、用户名、私钥或密码。公网地址与 SSH 地址可不同；如使用 Tailscale，SSH 地址填可达的 Tailscale IP。可以从已有主机选择跳板机。系统不会替你自动加入 Tailscale 网络。

测试失败仍可保存。首次连接会显示 SSH SHA256 指纹，应通过服务商控制台等可信渠道核验后再信任。跳板机和目标分别核验。VPS 详情可打开 SSH 终端、查看状态、生成独立 SSH config。

选择安装 / 更新 fq，任务中心显示 CPU 识别、上传、服务安装和核心校验。支持 Linux amd64 / arm64、systemd。非 root 用户需预先配置无交互 sudo。不会修改用户的现有 SSH config。

## 部署协议

在 VPS 编辑中读取并选择 Cloudflare Zone。每台 VPS 的独立 namespace 会自动生成，也可在未部署前修改。

进入部署中心，选择 VPS，再选择六种协议之一。公网 VPS 的端口填 0 可自动分配；NAT 必须填写内部监听和服务商已映射的公网端口，不支持端口跳跃。除 Snell 和 Reality 外，普通 TLS 服务需要申请证书。

VLESS + WS 可选择直连、CDN 或 Argo。CDN 分别填写 Edge HTTPS、公网回源、内部监听端口。普通 VPS 中公网和内部端口通常相同；NAT 以服务商映射为准。Cloudflare Zone 的 SSL 模式应允许 HTTPS 回源，建议正确配置 Full (strict)，不改动其他网站的设置。

CDN / Argo 会检查实际 Edge 证书覆盖。多级建议域名尚无 Edge 覆盖时，自动生成的名称会改为 cdn-namespace.zone / argo-namespace.zone；自定义多级域名则明确提示先在 Cloudflare 配置覆盖，不会自动购买付费服务。VPS 的泛域名证书继续保留，必要的一级服务域名加入其 SAN。

Argo 每 VPS 一个固定 Tunnel，内部使用 HTTP 回源，不需 VPS 公网监听 80 / 443。同步后会出现 443 TLS 和 80 HTTP 两个客户端节点。Tunnel 只有 HTTP / WebSocket 接入能力，不能用它承载 Hysteria2 / TUIC 的普通 UDP 服务。

Reality 使用握手目标和密钥，不需要普通 TLS 证书。UDP 协议需要服务商与系统防火墙实际允许 UDP，软件无法替代服务商端口开放。

## 网络服务与网站

网络服务选择 VPS 后读取 fq 配置。可检查状态、更新核心、打开实时日志、重启和删除服务。每个远程变更都生成备份并预检查，失败自动回滚。

网站填写域名、目标 IP、目标端口和 HTTP / HTTPS 回源。目标可运行在 3000、5201、8080、9000 等端口。Caddy 负责反向代理；公网默认直连，NAT 填已有公网映射，没有可用入站可选 Argo。网站域名必须属于所选 Cloudflare Zone；Gungun 申请证书并配置 DNS。HTTPS 回源需要上游证书有效。多个 HTTPS 网站可以共用内部监听端口；Argo 的内部 HTTP 与 HTTPS 网站需要使用不同内部端口，否则预检查会拒绝。

WARP 页面安装并连接服务器 WARP，然后在协议部署中选择 WARP 出站。只影响该协议，默认 DIRECT；不会修改 SSH 的全局路由。Cloudflare 的 WARP 包对系统版本有要求，不支持的系统会明确报错。

备份页面可创建备份、读取列表和恢复指定版本。恢复前仍备份当前状态，并校验备份完整清单和 SHA256；损坏或未完成的备份不会覆盖正在使用的配置。删除网站时保留 DNS，避免误删可能被其他服务使用的记录。

## 节点、订阅与聚合

VPS 详情点击“手动同步节点”，通过 SSH 调用 fq export。每 VPS 有独立 Tag；重新同步以 VPS 数据为准，覆盖本地对 VPS 节点的编辑。外部订阅使用“新建分组 → 外部订阅”，填 URL 后手动更新。手动导入支持分享链接、Base64、Mihomo YAML。

所有节点是虚拟分组。新建动态聚合时勾选多个 Tag；它们的节点会动态映射，不复制数据。同一 Tag 可加入多个聚合。

节点左键选中整行，双击查看不同测试主机的最新结果，右键 / 三点菜单编辑、测速、优选或删除。删除原始节点前会列出受影响链路，确认后一起删除。远程同步或订阅更新导致原始节点消失时会清理对应链路。

导出提供 V2Ray Base64 和 Mihomo YAML。Snell v6 及代理链不能用普通 V2Ray 分享格式完整表示，必须使用 Mihomo。导出文件包含节点凭据。

## 链式代理

进入独立“链式代理”Tag，创建链路，选择第一跳和最终出口。顺序表示 Mac → 第一跳 → 第二跳 → 最终目标；可上移 / 下移，也可扩展多跳。节点按 ID 引用，参数修改后自动读取最新值。

当前支持后续 TCP 拨号的 VLESS、AnyTLS、Snell 等组合；第二跳及以后 Hysteria2 / TUIC 需要 UDP 拨号，暂明确阻止。保存后执行测试；详情显示每一跳连接、错误、最终结果和完整链路下载速度。前一跳失败时，后续跳显示“未测试”，请先解决上游连接。不能只看单节点延迟判断整链可用。

用 Mihomo 导出链路时保留各跳 dialer-proxy 关系。链路不是一个可以直接粘贴到普通 V2Ray 订阅中的虚假链接。

## 测速与优选 IP

两个批量按钮分别测试真连接延迟和多线程延迟 + 速度，范围严格为当前 Tag。测试源可选 Mac 和其他 VPS，多选会对每个来源分别执行。自动排除 VPS 测试自身节点及包含自身节点的链路。列表的“显示来源”决定展示哪台主机结果；详情显示全部来源。

只有每个来源的最新结果，没有复杂历史曲线。进程启动时间不计入代理延迟；下载速度受候选线路、远程出口和下载站点共同影响，不保证跑满本机带宽。

CDN / Argo 节点的优选 IP 页面可以获取 Cloudflare 候选或手动填写。测试时只替换 Address，保持域名、SNI、路径和认证参数。点击“应用”后更新本机节点，不修改 VPS。候选 IP 仅从官方网段取样，不代表保证最佳线路。

## fq 命令

```sh
fq
fq status --json
fq list --json
fq log gungun-sing-box
fq restart --json
fq update v1.0.0
fq core update sing-box
fq warp status
fq warp install
fq backup
fq backup list
fq restore BACKUP_ID
fq export --json
fq uninstall --yes
```

`fq uninstall --yes` 停止并移除 Gungun 服务单元，默认保留配置和备份；加 `--purge` 才删除配置。第三方 core 和 fq 二进制不自动清除，避免删除可能仍在使用的文件。`fq update` 依赖可公开下载的 Release；私有仓库建议通过 Gungun 的 SSH 上传更新。

## 常见问题

- SSH 指纹未知 / 已变：独立核验后信任，不能跳过校验。
- sudo -n 失败：使用 root 或由管理员设置所需权限。
- UDP 协议失败：检查服务商 UDP、安全组、防火墙、映射以及回程。
- CDN 失败：核对 Edge 支持端口、公网回源和内部监听的映射、Zone SSL 模式与 DNS。
- Argo 失败：检查 cloudflared 日志、Tunnel ingress hostname 及服务商到 Cloudflare Tunnel 的出站网络。
- 证书续期：Mac 必须在线且可 SSH。应用每日检查；长期离线前手动续期。
- 配置回滚失败：保留任务错误与 backup ID，SSH 使用 fq restore 恢复，不要反复覆盖状态。


## 外观设置

设置 → 外观 → 应用主题，可选择“跟随系统”“浅色”“深色”，保存后立即应用到所有窗口并在下次启动恢复。默认跟随 macOS 外观变化。

所有实际协议测试与链式代理执行均由 sing-box 完成。Mihomo 是导出的 YAML 格式，无需安装 Mihomo。外部节点若带整张证书 SHA256 pin，sing-box 无法原样验证，会明确阻止测试；请使用可信证书或确认节点验证参数，程序不会自动关闭验证。

当前执行核心兼容性：Hysteria2 / TUIC 直接接 VLESS WS / Reality 的四种组合在真实下载回归中不稳定，暂时明确拒绝创建和执行。可使用 AnyTLS / Snell 作为中间跳，或选择 TCP 第一跳。已支持的组合需通过实际连接和下载；能力拒绝测试与真实连通测试分别计数，不把拒绝当成连通成功。
