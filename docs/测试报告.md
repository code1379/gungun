## 已知限制

1. macOS 仅提供 Apple Silicon arm64，满足 M1 Pro；不提供 Intel DMG。
2. 自动证书续期依赖 Mac 在线且能 SSH，Global API Key 不下发 VPS。
3. Hysteria2 / TUIC 可以作为第一跳；第二跳及以后需要 UDP 拨号，首版明确拒绝。
4. Snell v6 和代理链必须使用 Mihomo YAML；普通 V2Ray Base64 无法完整表达这些关系。
5. 首版节点与服务模型限于六种协议；不静默丢弃不支持协议、VLESS ENC 或链路配置。
6. fq 服务管理要求 systemd；WARP 自动安装限于代码列出的 Debian / Ubuntu apt 系统。
7. 私有仓库的 fq 自更新可通过桌面 SSH 上传；直接 fq update 需要可下载的 Release。
8. Cloudflare 默认 Universal SSL 通常不覆盖任意多级域名。自动 CDN / Argo 名称必要时回退到独立一级名称；自定义多级名称需已有 Edge 证书覆盖，不自动购买付费证书。
9. Actions Artifact 上传曾遭遇账号存储配额。测试上传失败会保留错误，不影响真实构建结论；正式资产通过草稿 Release 暂存并统一发布，手动测试仍仅上传 Artifact。
