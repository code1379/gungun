### 当前限制与尚未解决事项

- **Swift 原生类型检查的已知编译错误修正后待复验，XPC / 注册 / 授权未完成实测**，这些接口、签名与 `.app` 布局必须真机验证，可能需要后续修正。开发模式没有特权写入后门；已签名 app 的系统批准仍由 macOS 管理。
- 本机真实连接与新增 UI 未在当前环境验收，不能宣布三个模块全部完成。
- 外部代理设置发生冲突时自动恢复停止，需要人工核验混合状态；不能承诺冲突状态下一键恢复。
- Cloudflare 没有跨客户端条件事务保障；应用内串行和快照检查不能消除远端最后一刻并发写入。
- 旧 DNS 记录保守视为外部，需要明确接管；未有本地节点或路由库存的旧 Tunnel 路由保守只读，重新部署协调后才能管理。外部按路径路由、SRV / CAA 结构化编辑使用官方控制台。
- 节点切换有短暂重连窗口；不迁移已有 TCP 会话。后台守护恢复延迟与重启流程仍待实测。
- 无 TUN、无 Xray / Mihomo 运行、无 Tailscale 自动安装；未改造持久化任务重试。
- 自动 Actions 暂停、ready=false、无 DMG、无临时 Artifact；本轮没有触发远程 CI。

## 当前构建与发布策略

- 按用户要求，普通 CI 和手动 CI 不生成 DMG、不上传临时 Actions Artifact；发布开关 `docs/release.json` 保持 `ready=false`。
- 本地运行：`pnpm install --frozen-lockfile` → `pnpm prepare:dev` → `pnpm dev`。macOS Apple Silicon 无需预装 Go；准备步骤下载官方 Go 1.25.4 并校验 SHA256，再构建 fq 与准备 sing-box。
- 本次源码测试通过不代表当前 DMG 已验收。恢复正式发布后，必须重新通过 arm64 DMG 构建、挂载、复制安装、启动及包内 sing-box / fq 架构检查。
- 正式发布门禁读取单元测试、20 组真实链路、4 组拒绝、Linux 服务、Mac 双跳、主题、终端会话及安装证据；证据不完整时拒绝公开。最终报告、SHA256SUMS 与资产一起发布。

## 已知能力限制

1. 首版限定上述六种协议；不支持 Xray、VLESS ENC，也不导出 sing-box JSON 订阅。
2. 后续跳不支持 Hysteria2 / TUIC UDP 拨号；上述 4 种不稳定组合在保存及执行时明确拒绝。
3. Snell v6 和代理链使用 Mihomo YAML 导出；Mihomo 仅为导入导出格式，不下载或运行其核心。
4. sing-box 的公钥 pin 与整张证书 SHA256 pin 不等价。外部节点的整证书指纹可保留，但执行时明确阻止，不静默忽略或关闭验证。
5. fq 服务管理需要 systemd；WARP 自动安装限于代码列出的 Debian / Ubuntu apt 系统。
6. Cloudflare 自动命名优先检查实际 Edge 证书覆盖；多级域名未覆盖时自动名称可以回退为独立一级名称，自定义域名不静默修改，也不自动购买证书。
