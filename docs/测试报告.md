## 已知限制

1. 自动证书续期依赖 Mac 在线；不把 Global API Key 下发给 VPS。
2. 后续跳 UDP 拨号暂不支持，Hysteria2 / TUIC 不可作第二跳及以后；客户端会明确拒绝。
3. Snell v6 / 代理链需 Mihomo YAML，不能表达为普通 V2Ray Base64。
4. 远程服务需 systemd；WARP 自动安装面向列出的 Debian / Ubuntu apt 版本。
5. fq 自更新需要可访问的 Release，私有仓库通过桌面端 SSH 上传更新。
6. 未提供 Cloudflare 账号、真实 VPS、NAT 映射或 Apple 凭据；相关验收不会伪造为通过。
7. Cloudflare Full setup 的默认 Universal SSL 通常只覆盖 Zone apex 和一级子域名；更深层域名必须已有对应 Edge 证书。服务端泛域名证书不能替代 Cloudflare Edge 证书。自动域名会在必要时回退到兼容一级名称，不自动购买付费证书。
